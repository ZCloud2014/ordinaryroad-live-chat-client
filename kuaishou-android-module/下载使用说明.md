## ⚙️ 集成到Android项目

### 步骤1：修改 settings.gradle

在项目根目录的 `settings.gradle` 中添加：

```gradle
include ':app'
include ':kuaishou-android-module'  // 添加这一行
```

### 步骤2：添加依赖

在 `app/build.gradle` 中添加：

```gradle
dependencies {
    // 添加快手直播模块
    implementation project(':kuaishou-android-module')
}
```

### 步骤3：同步项目

在Android Studio中点击 "Sync Now" 或执行：
```bash
./gradlew build
```

## 🚀 5分钟快速开始

### 最简单的示例

```java
import com.kuaishou.live.client.KuaishouLiveClient;
import com.kuaishou.live.listener.SimpleKuaishouLiveListener;
import com.kuaishou.live.model.DanmuMessage;

public class MainActivity extends AppCompatActivity {

    private KuaishouLiveClient liveClient;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        // 创建客户端
        liveClient = new KuaishouLiveClient("3x4av52pnmw8mta",
            new SimpleKuaishouLiveListener() {
                @Override
                public void onConnected() {
                    Log.d("Kuaishou", "✅ 连接成功！");
                }

                @Override
                public void onDanmuMessage(DanmuMessage danmu) {
                    // 收到弹幕
                    Log.d("Kuaishou", danmu.getUsername() + ": " + danmu.getContent());
                }
            });

        // 开始连接
        liveClient.start();
    }

    @Override
    protected void onDestroy() {
        super.onDestroy();
        if (liveClient != null) {
            liveClient.stop();
        }
    }
}
```

**就这么简单！** 🎉

## 🔧 常见问题

### Q: 编译时提示找不到某个类？

**A:** 确保在 `settings.gradle` 中正确添加了模块：
```gradle
include ':kuaishou-android-module'
```

### Q: 收不到弹幕消息？

**A:** 检查以下几点：
1. 主播是否正在直播
2. 房间ID是否正确
3. 是否调用了 `liveClient.start()`
4. 查看Logcat日志

### Q: 如何获取房间ID？

**A:**
- 方法1：从直播间URL获取（如 `https://live.kuaishou.com/u/3x4av52pnmw8mta` 中的 `3x4av52pnmw8mta`）
- 方法2：使用用户ID（通常也能工作）

### Q: Cookie从哪里获取？

**A:** 详见 `本地使用指南.md` 的 "使用Cookie" 部分，包含详细的图文教程。

### Q: 模块占用内存多大？

**A:** 通常5-10MB，取决于直播间活跃度。

## 🔐 安全提示

### ⚠️ 重要警告

1. **不要泄露Cookie**：Cookie包含你的登录信息
2. **不要硬编码Cookie**：使用加密存储或让用户输入
3. **尊重用户隐私**：不要滥用收集到的数据
4. **遵守服务条款**：不要违反快手的使用协议

### 建议做法

```java
// ❌ 不要这样做
String cookie = "你的真实Cookie"; // 危险！

// ✅ 应该这样做
SharedPreferences prefs = getSharedPreferences("secure", MODE_PRIVATE);
String cookie = prefs.getString("cookie", "");

// ✅ 或使用Android Keystore加密存储
```
