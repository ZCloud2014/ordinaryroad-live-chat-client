# 如何单独编译快手直播模块

如果你想单独编译这个模块（不集成到现有项目），按以下步骤操作：

## 方法一：使用Android Studio

### 1. 打开项目

1. 启动Android Studio
2. 选择 "Open an Existing Project"
3. 选择 `kuaishou-android-module` 文件夹
4. 等待Gradle同步完成

### 2. 重命名文件（重要）

在Android Studio中：
1. 将 `root-build.gradle` 重命名为 `build.gradle`
2. 删除或重命名原来的 `build.gradle` 为 `module-build.gradle`

或在命令行：
```bash
cd kuaishou-android-module
mv build.gradle module-build.gradle
mv root-build.gradle build.gradle
```

### 3. 修改 settings.gradle

打开 `settings.gradle`，内容应该是：
```gradle
rootProject.name = "kuaishou-live-module"
include ':kuaishou-android-module'
project(':kuaishou-android-module').projectDir = new File(settingsDir, '.')
```

### 4. 同步并编译

1. 点击 "Sync Now"
2. 选择 Build > Make Project
3. 编译成功后会生成AAR文件

## 方法二：使用命令行

```bash
cd kuaishou-android-module

# 重命名文件
mv build.gradle module-build.gradle
mv root-build.gradle build.gradle

# 编译
./gradlew build

# 生成的AAR文件位置：
# build/outputs/aar/kuaishou-android-module-release.aar
```

## 生成的AAR文件使用方法

### 1. 复制AAR到你的项目

```
your-android-project/
└── app/
    └── libs/
        └── kuaishou-live-module.aar  # 复制到这里
```

### 2. 在 app/build.gradle 中添加

```gradle
dependencies {
    implementation files('libs/kuaishou-live-module.aar')

    // 还需要添加依赖的库
    implementation 'com.squareup.okhttp3:okhttp:4.12.0'
    implementation 'org.json:json:20230227'
    implementation 'com.google.protobuf:protobuf-java:3.25.1'
}
```

## 注意事项

- 如果只是集成到现有项目，**不需要**单独编译
- 直接使用源码集成更方便调试和定制
- AAR文件适合作为第三方库分发
