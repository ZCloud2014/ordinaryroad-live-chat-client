## 🚀 开始使用

### 最简单的使用示例

```java
import com.kuaishou.live.client.KuaishouLiveClient;
import com.kuaishou.live.listener.SimpleKuaishouLiveListener;
import com.kuaishou.live.model.*;

public class MainActivity extends AppCompatActivity {

    private KuaishouLiveClient liveClient;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        // 创建监听器
        SimpleKuaishouLiveListener listener = new SimpleKuaishouLiveListener() {
            @Override
            public void onConnected() {
                Log.d("Kuaishou", "✅ 连接成功！");
            }

            @Override
            public void onDanmuMessage(DanmuMessage danmu) {
                Log.d("Kuaishou", String.format("💬 %s: %s",
                    danmu.getUsername(), danmu.getContent()));
            }

            @Override
            public void onGiftMessage(GiftMessage gift) {
                Log.d("Kuaishou", String.format("🎁 %s 送出 %s x%d",
                    gift.getUsername(), gift.getGiftName(), gift.getGiftCount()));
            }

            @Override
            public void onError(Exception error) {
                Log.e("Kuaishou", "❌ 错误", error);
            }
        };

        // 创建客户端（房间ID或用户ID）
        liveClient = new KuaishouLiveClient("3x4av52pnmw8mta", listener);

        // 开始连接
        liveClient.start();
    }

    @Override
    protected void onDestroy() {
        super.onDestroy();
        if (liveClient != null) {
            liveClient.stop();
        }
    }
}
```

## 🔐 使用Cookie（发送弹幕/点赞）

### 1. 获取Cookie

**从Chrome浏览器获取：**

1. 打开Chrome，访问快手直播间
2. 按F12打开开发者工具
3. 切换到 **Network** 标签
4. 刷新页面
5. 点击任意请求，查看 **Request Headers**
6. 复制 **Cookie** 值
7. 复制 **Kww** 值（可选，但推荐）

### 2. 在代码中使用

```java
String cookie = "你从浏览器复制的Cookie";
String kww = "你从浏览器复制的Kww值";

liveClient = new KuaishouLiveClient(roomId, cookie, kww, listener);
liveClient.start();

// 发送弹幕
liveClient.sendDanmu("大家好！");

// 点赞10次
liveClient.clickLike(10);
```

### ⚠️ Cookie安全提示

**不要在代码中硬编码Cookie！** 推荐做法：

```java
// 1. 使用SharedPreferences存储
SharedPreferences prefs = getSharedPreferences("kuaishou", MODE_PRIVATE);
String cookie = prefs.getString("cookie", "");

// 2. 使用加密存储
// 3. 在设置界面让用户输入
```

## 🛠️ 常见问题

### Q1: 编译错误 "Cannot resolve symbol 'Protobuf'"

**解决方案：**
确保 `build.gradle` 中包含Protobuf依赖：
```gradle
implementation 'com.google.protobuf:protobuf-java:3.25.1'
```

### Q2: 连接失败 "无法获取WebSocket地址"

**原因：**
- 主播可能未开播
- 房间ID错误

**解决方案：**
```java
liveClient = new KuaishouLiveClient(roomId, new SimpleKuaishouLiveListener() {
    @Override
    public void onError(Exception error) {
        // 检查错误信息
        Log.e("Kuaishou", "错误: " + error.getMessage());
    }
});
```

### Q3: 收不到弹幕消息

**检查清单：**
- [ ] 是否调用了 `liveClient.start()`
- [ ] 是否实现了 `onDanmuMessage()` 回调
- [ ] 主播是否正在直播
- [ ] 查看Logcat是否有错误日志

### Q4: 发送弹幕失败

**原因：**
- Cookie未设置或已过期
- 发送频率过快

**解决方案：**
```java
// 1. 确保提供了Cookie
liveClient = new KuaishouLiveClient(roomId, cookie, kww, listener);

// 2. 控制发送频率（建议间隔1-2秒）
handler.postDelayed(() -> {
    liveClient.sendDanmu("消息");
}, 2000);
```

### Q5: 如何在后台运行？

**使用Service：**
```java
public class LiveMonitorService extends Service {
    private KuaishouLiveClient liveClient;

    @Override
    public int onStartCommand(Intent intent, int flags, int startId) {
        // 创建客户端
        liveClient = new KuaishouLiveClient(...);
        liveClient.start();

        // 保持服务运行
        return START_STICKY;
    }
}
```

**在AndroidManifest.xml中注册：**
```xml
<service android:name=".LiveMonitorService" />
```

## 🎯 高级用法

### 1. 多房间监听

```java
List<KuaishouLiveClient> clients = new ArrayList<>();

for (String roomId : roomIds) {
    KuaishouLiveClient client = new KuaishouLiveClient(roomId, listener);
    client.start();
    clients.add(client);
}

// 停止所有
for (KuaishouLiveClient client : clients) {
    client.stop();
}
```

### 2. 自定义重连策略

```java
new SimpleKuaishouLiveListener() {
    private int reconnectCount = 0;

    @Override
    public void onDisconnected(String reason) {
        if (reconnectCount < 5) {
            long delay = (long) Math.pow(2, reconnectCount) * 1000;
            handler.postDelayed(() -> {
                liveClient.start();
                reconnectCount++;
            }, delay);
        }
    }

    @Override
    public void onConnected() {
        reconnectCount = 0; // 重置计数
    }
}
```

### 3. 弹幕过滤器

```java
new SimpleKuaishouLiveListener() {
    @Override
    public void onDanmuMessage(DanmuMessage danmu) {
        String content = danmu.getContent();

        // 过滤广告
        if (content.contains("广告") || content.contains("加微信")) {
            return;
        }

        // 过滤敏感词
        String[] keywords = {"关键词1", "关键词2"};
        for (String keyword : keywords) {
            if (content.contains(keyword)) {
                handleKeyword(danmu, keyword);
            }
        }
    }
}
```

### 4. 统计分析

```java
class DanmuAnalyzer extends SimpleKuaishouLiveListener {
    private Map<String, Integer> userActivity = new HashMap<>();
    private int totalDanmu = 0;
    private int totalGift = 0;

    @Override
    public void onDanmuMessage(DanmuMessage danmu) {
        totalDanmu++;
        String uid = danmu.getUid();
        userActivity.put(uid, userActivity.getOrDefault(uid, 0) + 1);
    }

    @Override
    public void onGiftMessage(GiftMessage gift) {
        totalGift += gift.getGiftCount();
    }

    public void printStatistics() {
        Log.d("Stats", "总弹幕数: " + totalDanmu);
        Log.d("Stats", "总礼物数: " + totalGift);
        Log.d("Stats", "活跃用户: " + userActivity.size());
    }
}
```
